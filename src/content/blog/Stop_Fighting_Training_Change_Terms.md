Trying to block model training is a losing war.

Crawlers will crawl. Mirrors will mirror. Lawyers will stall. If you have worked in open-source software long enough, you have seen this pattern: a new extraction method shows up, people try to plug the obvious holes, and the extractors route around the damage. The result is usually a lot of motion, a lot of anger, and not much leverage.

Hong Minhee’s essay, “Histomat of free and open-source software: We should reclaim large language models, not reject them,” makes a harder point: refusal is not strategy. Blocking scrapers, leaving platforms, or treating anyone who uses automated coding tools as a traitor might feel righteous, but it does not change the underlying ownership story.

From a historical materialism lens, that is the key: the battleground is ownership, not vibes.

Open-source licensing has always been a practical response to new forms of enclosure. The GNU General Public License version 2 kept sharing obligations intact as software distribution scaled. The GNU General Public License version 3 closed loopholes around hardware lock-down. The Affero General Public License addressed the “software as a service” loophole where code could be used without being distributed. Each step was less about purity and more about updating the rules of reciprocity as the mode of production changed.

Large language models are the next shift in the mode of production for software. Training turns public code into private capability. And current licenses were not written with model training in mind.

So here is the move: stop fighting training. Start changing the terms.

The proposal is a new “training copyleft” license: train on open-source code, fine. But if the model learns from our commons, the model weights stay free. Publish the training sources. Make fine-tuning inherit the same duties. Even selling access through an application programming interface counts as distribution.

This is not about rejecting the tools. It is about reclaiming the value they derive from shared work, and making sure the outputs stay in the commons rather than getting fenced off.

If open-source communities want leverage, the most productive fight is not against the existence of large language models. It is for a licensing upgrade that makes reciprocity enforceable in the world we actually live in.
